Data-Enabled Predictive Control for Adaptive V2X Resource Allocation

Pioneering application of DeePC (Data-Enabled Predictive Control) to V2X networks, using Hankel matrices and Willems' Fundamental Lemma to achieve model-free adaptive control for safety-critical vehicular communication under extreme traffic densities.

Key Results:

  • Zero safety constraint violations (PRR ≥70%, CBR ≤75%) across 100 test episodes vs. 100% baseline failure rate
  • 46% channel congestion reduction (80.4% → 43.6% CBR) preventing network saturation
  • 53% latency improvement (197ms → 92ms delay) meeting 3GPP safety requirements
  • 4× density extrapolation: trained on 50-100 veh/km, successfully deployed at 250-400 veh/km extreme congestion

Technical Innovation:

  • Model-free control using Hankel matrices (35×709 dimensions) bypassing complex wireless system modeling
  • Quadratic programming with 709 decision variables achieving real-time performance (164ms solve time)
  • Traffic-adaptive cost functions with density-dependent references enabling graceful degradation
  • 715 training trajectories from LTE-V2V-Sim v5.4 with NGSIM I-80 realistic vehicle mobility
  • Validated quasi-LTI behavior via ANOVA analysis (p>0.84) justifying DeePC theoretical foundations

Technologies:

DeePC Hankel Matrices LTE-V2V-Sim v5.4 MATLAB Quadratic Programming 3GPP Mode 4 NGSIM Dataset Willems' Lemma
